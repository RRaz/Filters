# RRAZ Depth — notes

These are the photographer’s notes, kept separately from the installer. For
installation, use the
[RRAZ Depth 1.0.0 release](https://github.com/RRaz/Filters/releases/tag/depth-1.0.0),
not this folder.

- [Photographer’s notes (PDF)](Depth.pdf)

**The notes are a placeholder while they are being written.** The file name will
not change when the finished notes replace it, so links stay valid. An example
