RRAZ filters for Affinity 3

Standalone filters for Windows 10 and 11 (64-bit)  ·  each with its own installer
These filters only work on 16-bit rasterised images.
A 16-bit per channel pixel layer, in RGB or greyscale. 8-bit and 32-bit HDR documents cannot be processed.

RRAZ Deblur

Recovers detail from defocus and motion blur. Needs an NVIDIA graphics card with driver 580 or newer.

RRAZ Depth

Builds a 16-bit greyscale depth map from the active layer. Runs on the processor, so no graphics card is needed.

Installing a filter

  1. Click Download and install and download the setup, the runtime and the installation sheet.
  2. Keep the setup and the runtime in the same folder, then run the setup. Do not unzip the runtime.
  3. In Affinity, open Settings > Photoshop Plugins and add %LOCALAPPDATA%\RRAZ\Affinity.

That folder is normally C:\Users\<you>\AppData\Local\RRAZ\Affinity. You only add it once: after that, every RRAZ filter you install appears in the menu. The setup finish page shows the exact address for your account.

Setting up the folder in Affinity (PDF)

What this is

Each filter is installed separately and removed separately. The install is per user, needs no administrator rights, and writes only inside %LOCALAPPDATA%\RRAZ. There is no account, no upload and no server: no image ever leaves the computer.
